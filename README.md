# HotelReservationSystem

Aleksi Nieminen, 25TietoB

Suoritettu 5p mukaisesti

A C++ console-based hotel room reservation system that allows users to generate or load hotel room data, make reservations, and search existing bookings. The program supports single and double rooms, automatically generates unique reservation IDs, calculates nightly prices with random discounts, and saves reservation data to a .txt file for persistence between sessions.

The project demonstrates the use of structs, enum classes, vectors, file I/O, input validation, functions, and basic randomization in C++.
